# MCP Registry (Official)

https://registry.modelcontextprotocol.io

The canonical registry maintained by the Model Context Protocol project. Hosts metadata only — packages (npm, PyPI, etc.) must be published to their own registries first.

Currently in preview (v0.1 API freeze since Sept 2025). Breaking changes or data resets may occur before GA.

## Auth method

GitHub OAuth device flow. No env var token needed — credentials are stored locally by the CLI after `mcp-publisher login github`.

Namespace ownership is enforced at publish time:
- GitHub auth → server name **must** start with `io.github.<your-github-username>/`
- Custom domain (e.g. `com.example`) → requires DNS or HTTP verification (see [authentication docs](https://modelcontextprotocol.io/registry/authentication))

## Publish method

`mcp-publisher` CLI — install, login, create `server.json`, publish.

```bash
# Install (macOS/Linux binary)
curl -L "https://github.com/modelcontextprotocol/registry/releases/latest/download/mcp-publisher_$(uname -s | tr '[:upper:]' '[:lower:]')_$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/').tar.gz" | tar xz mcp-publisher && sudo mv mcp-publisher /usr/local/bin/

# Or Homebrew
brew install mcp-publisher
```

## server.json format

Schema: `https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json`

Generated by `mcp-publisher init`. Required fields:

| Field | Required | Notes |
|---|---|---|
| `$schema` | yes | schema URL above |
| `name` | yes | reverse-DNS id, e.g. `io.github.username/server-name` |
| `description` | yes | short description |
| `version` | yes | semver matching package version |
| `repository.url` | yes | GitHub repo URL |
| `repository.source` | yes | `"github"` |
| `packages[].registryType` | yes | `npm`, `pypi`, `cargo`, `nuget`, `oci`, `mcpb` |
| `packages[].identifier` | yes | package name, e.g. `@username/mcp-server` |
| `packages[].version` | yes | semver |
| `packages[].transport.type` | yes | `stdio`, `streamable-http`, or `sse` |

Optional but useful:
- `title` — human-readable display name
- `websiteUrl`
- `packages[].environmentVariables[]` — array of `{name, description, isRequired, isSecret}`
- `packages[].runtimeHint` — e.g. `"npx"`, `"uvx"`
- `remotes[]` — for remote/hosted servers

npm-specific requirement: add `"mcpName": "io.github.username/server-name"` to `package.json` before publishing to npm — the registry validates this matches `server.json`'s `name`.

## Step-by-step

**Prerequisites:** publish the package to npm/PyPI/etc. first. The registry stores metadata only.

1. **Add `mcpName` to `package.json`** (npm packages):
   ```json
   "mcpName": "io.github.your-username/your-server"
   ```

2. **Publish package to npm** (if not already):
   ```bash
   npm publish --access public
   ```

3. **Install `mcp-publisher`** (see above).

4. **Generate `server.json`** in the repo root:
   ```bash
   mcp-publisher init
   ```
   Edit the generated file — update `version`, remove placeholder env vars, fill in `description`.

5. **Authenticate** (browser step — GitHub device flow):
   ```bash
   mcp-publisher login github
   # Prints a device code; visit https://github.com/login/device and enter it
   ```

6. **Publish:**
   ```bash
   mcp-publisher publish
   # Optional: --dry-run to validate without publishing
   # Optional: --file=./path/to/server.json
   ```

7. **Verify:**
   ```bash
   curl "https://registry.modelcontextprotocol.io/v0.1/servers?search=io.github.your-username/your-server"
   ```

## Troubleshooting

| Error | Fix |
|---|---|
| "Registry validation failed for package" | `mcpName` in `package.json` missing or doesn't match `server.json` `name` |
| "Invalid or expired Registry JWT token" | Re-run `mcp-publisher login github` |
| "You do not have permission to publish this server" | Server name doesn't start with `io.github.your-github-username/` |

## Notes

- `mcp-publisher login` stores auth locally; no env var needed for CI. For GitHub Actions, use OIDC — see [github-actions docs](https://modelcontextprotocol.io/registry/github-actions).
- Registry API: `https://registry.modelcontextprotocol.io/v0.1/servers` (GET with `?search=` or `?id=`)
- Docs: https://modelcontextprotocol.io/registry/quickstart
