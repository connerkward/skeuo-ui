# mcp-get (Deprecated)

https://mcp-get.com

## Status

**Deprecated as of late 2024. No longer maintained.**

The maintainer's README states the project has moved. The repository (`github.com/michaellatman/mcp-get`) is not accepting new submissions and has not been updated since November 2025. The CLI still functions for existing installs but the registry is frozen.

## Recommendation

Submit to **[Smithery](https://smithery.ai)** instead — it is the explicitly recommended successor for MCP server discovery, installation, and registry listing. See `platforms/smithery.md` if that doc exists, or submit directly at https://smithery.ai.

The official Anthropic-backed registry is at https://registry.modelcontextprotocol.io — see `platforms/mcp-registry.md`.
